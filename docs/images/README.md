# 截图

把下面四张图存到本目录，文件名不要改。截完告诉我，我再把 README 里的裂图说明收掉（如果 GitHub 已能显示就不用动）。

浏览器拉到约 1920 宽。不要把 `.env`、API Key、本机盘符特写进画面。问句用界面空态里的示例即可。

## 1. `workbench.png` — 工作台

1. 新开一轮对话。
2. 问一句能出表的，例如「当前一共有多少个项目？」。
3. 等右侧产物栏出现 SQL 和结果表。
4. **整窗截图**。要看见：左侧会话、中间对话和委派 DAG、右侧 SQL / 表。
5. 不要打开轨迹抽屉。

## 2. `delegation.png` — 委派

1. 同一套界面，问一句要出图的，例如「用柱状图对比各项目的建筑面积」。
2. 等 DAG 上能看出 **NL2SQL → Plot**，右侧有图。
3. 截中间 DAG + 右侧产物，或再截一张整窗。

## 3. `context.png` — 上下文

1. 不要新开会话，在上一轮后面再追问一句。
2. 打开顶栏 / 侧边的 **上下文占用** 或 **Prompt 清单**。
3. 截这一块（可以带一点对话作上下文）。要能看出主 Agent / 子 Agent，以及大结果没有整段塞进 prompt。

## 4. `trajectory.png` — 轨迹

1. 同一轮结果还在时，打开轨迹面板。
2. 截能看见节点阶段或 span 的那一屏。
3. 不必再露出整张工作台。
