## 一页四条（可直接贴）

面向数据分析场景的多 Agent 协作系统：自研 Flex 运行时，支持 NL2SQL 与任务分解，聚焦运行时扩展、子 Agent 隔离与上下文治理。

1. **可配置运行时与钩子**：基于 LangGraph 实现 PRE / Actor / Post 三阶段工作流；Agent / Node / Tool 三级钩子由 YAML（及 Suite）声明注册，业务扩展与主循环解耦；内置可选的端到端耗时 / token 采集与可落盘轨迹，支撑离线定位。

2. **主从协作与进程隔离**：主 Agent 规划调度，子 Agent 以独立子进程执行；支持按工作区复用多轮对话与中间产物（磁盘 hydrate，非进程常驻），Swarm 路径辅以文件锁与同轮冲突检测保障并发安全。

3. **NL2SQL 闭环**：感知→生成→校验→反思→执行→选择六节点；感知阶段语义 schema linking 缩表（Landcheck 子集 9 题必含表召回 **100%**，相对全库暴露表数中位下降约 **53%**）；SQLGlot AST 只读与函数白名单校验，失败自动反思修复；在同子集上执行结果与黄金 SQL 一致率 **100%**。

4. **DAG 轨迹与 IR**：用 DAG 记录执行路径与数据依赖；IR 统一管理 Query / State / Action 与产物；大结果落盘、模型侧以引用与摘要替换，结合裁剪与摘要缓存控制上下文膨胀，支持跨轮复用与轨迹追溯。
